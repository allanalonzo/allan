# Allan Calorie Tracker

This repository contains a simple front-end application for tracking calories and macronutrients.

## Getting Started

1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
   Parcel will serve the app at [http://localhost:1234](http://localhost:1234).

## Project Structure

- `frontend/index.html` – main HTML file.
- `frontend/src/index.jsx` – React entry point.
- `frontend/src/App.jsx` – application component with a form to add calorie and macro entries.

## Build

To create an optimized build:

```bash
npm run build
```

The output will be in the `dist` folder.
